Selective Speech Enhancement: Removing Requested Degradations While Preserving Acoustic Context

Listening examples demonstrate selective removal across five acoustic degradations. Each degraded input identifies the degradations it contains, and every model output is paired with the exact waveform target for its request.

How to listen

Compare the output with its target

First listen to each degraded input. For each request, compare the selective model output with the matched target. Requested degradations should be removed; degradations marked retained should remain audible.

Test speech: VCTK speakers p278 and p330. Ambient recordings: WHAM! test set. Foreground events: FSD50K evaluation clip 428860 by buzzmsc (CC BY 4.0) and clip 117120 by UncleSigmund (CC0 1.0).
